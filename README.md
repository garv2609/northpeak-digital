# NorthPeak Digital Landing Page

A modern, fully responsive landing page developed as part of the **NorthPeak Digital Internship Assignment**. The project focuses on clean UI design, responsive layouts, smooth user interactions, and modern frontend development practices.

## 🚀 Live Demo

https://northpeak-digital-lime.vercel.app/

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern and clean UI
- Sticky navigation bar
- Smooth scrolling navigation
- Interactive mobile menu
- Pricing section
- Services section
- Call-to-action sections
- Contact section
- Hover animations and transitions
- Cross-browser compatibility

## 📱 Responsive Breakpoints

- Desktop (1440px+)
- Laptop (1024px)
- Tablet (768px)
- Mobile (360px)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts (Manrope)
- Lucide Icons

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/garv2609/northpeak-digital.git
```

Open the project folder:

```bash
cd northpeak-digital
```

Launch the project by opening `index.html` in your browser.

No installation or build tools are required.
